# UTN FRM MCP — landing

Sitio de producto de UTN FRM MCP, un servidor MCP para consultar información de UTN FRM Mendoza desde asistentes de IA. Proyecto independiente, no pertenece a la Universidad Tecnológica Nacional.

Servidor MCP: https://github.com/BautistaAlosMartorell/utnfrm-mcp

## Desarrollo

Requiere Node.js 22.13 o posterior.

```bash
npm install
npm run dev     # http://localhost:3000
npm run build
```

Next.js (App Router), sitio estático. El contenido está en `lib/content.ts`.
